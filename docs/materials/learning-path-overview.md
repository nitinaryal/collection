## Purpose

Learning paths in this collection help you move from orientation to enterprise-ready practice without drowning in disconnected tutorials.

## How to follow a path

1. **Clarify the role** — engineer, lead, architect, or platform.
2. **Pick a goal** — adopt a framework, evaluate a tool, or raise delivery standards.
3. **Start with Materials** — short overviews and glossaries.
4. **Go deep in Frameworks / Tools** — production and enterprise sections.
5. **Apply Architecture + Standards** — decisions, constraints, and baselines.
6. **Use Templates** — ADRs, checklists, and evaluations on real work.

## Suggested starter path (general)

| Step | Category | Outcome |
|------|----------|---------|
| 1 | Materials → Glossary | Shared vocabulary |
| 2 | Standards → (your coding/API baseline) | Minimum quality bar |
| 3 | Frameworks or Tools → chosen topic | Practical competence |
| 4 | Architecture → relevant pattern | Sound trade-offs |
| 5 | Templates → ADR + release checklist | Repeatable delivery |
