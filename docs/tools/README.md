## Scope

- Build and package tooling
- CI/CD and release automation
- Cloud, containers, and infrastructure tooling
- Observability, quality, and collaboration tools
- Enterprise considerations: SSO, audit, RBAC, cost, support

## Suggested topics

- Git and code review workflows
- CI systems (GitHub Actions, Azure DevOps, Jenkins, GitLab CI)
- Containers and orchestration (Docker, Kubernetes)
- Observability stacks (logs, metrics, traces)
- Secret management and policy-as-code tools

## Document checklist

- [ ] Problem the tool solves
- [ ] Fit for team size / enterprise constraints
- [ ] Security and operational risks
- [ ] Minimal viable adoption path
- [ ] Links to Standards and Templates where useful
