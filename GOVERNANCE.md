# Governance

**Collection** is an open-source documentation project maintained by **YankiDev** ([yankidev.com](https://yankidev.com)).

## Roles

| Role | Responsibility |
|------|----------------|
| **Maintainer (YankiDev)** | Final decisions on scope, licensing, releases, and moderation |
| **Contributors** | Propose and improve documents via issues and pull requests |
| **Users** | Consume materials; report gaps and inaccuracies |

## Decision making

- Day-to-day content changes: reviewed via pull requests
- Taxonomy / category changes: discussed in an issue before large moves
- License or copyright changes: maintainer decision only
- Code of Conduct enforcement: maintainers per [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

## Releases

- Meaningful milestones may be tagged (see [CHANGELOG.md](CHANGELOG.md))
- Documentation may ship continuously on `main` between tags
