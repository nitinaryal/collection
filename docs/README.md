## How to use this collection

1. Pick a category that matches your goal (learn a framework, choose a tool, adopt a standard).
2. Read the category README for scope and conventions.
3. Prefer documents marked with clear **status** (`draft`, `stable`, `deprecated`).
4. Adapt templates to your organization’s naming, compliance, and risk context.

## Document front matter (recommended)

New documents should start with a short metadata block:

```markdown
# Title

| Field | Value |
|-------|-------|
| Status | draft \| stable \| deprecated |
| Audience | engineers \| architects \| leads |
| Level | intro \| intermediate \| advanced |
| Last reviewed | YYYY-MM-DD |
| Owner | YankiDev / contributor handle |
```
