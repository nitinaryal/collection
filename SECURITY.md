# Security Policy

**Collection** is primarily a documentation and materials repository maintained by
**YankiDev** ([yankidev.com](https://yankidev.com)).

## Supported versions

Security fixes apply to the latest content on the default branch (`main`).

| Branch | Supported |
|--------|-----------|
| `main` | Yes |
| Older tags / forks | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Instead, report privately via:

- Website contact: [https://yankidev.com](https://yankidev.com)

Include:

1. Description of the issue
2. Affected files or paths (if applicable)
3. Potential impact
4. Steps to reproduce (if applicable)
5. Suggested remediation (optional)

## What to report

Even in a documentation project, please report:

- Accidental exposure of secrets, credentials, or private URLs in docs
- Malicious or misleading instructions that could cause security harm
- Compromised CI/CD configuration if/when automation is added
- Supply-chain concerns in published packages or scripts (if added later)

## Response expectations

We aim to:

- Acknowledge valid reports within **7 days**
- Provide an initial assessment within **14 days** when feasible
- Coordinate disclosure for confirmed issues

## Safe Harbor

We appreciate good-faith security research. Please avoid privacy violations,
service disruption, and access to data that is not your own.
