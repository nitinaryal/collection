# Support

Thank you for using **Collection**, maintained by **YankiDev** ([yankidev.com](https://yankidev.com)).

## How to get help

| Need | Where |
|------|--------|
| Content questions / clarifications | Open a GitHub Discussion or Issue |
| Corrections / improvements | Pull request — see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security concerns | [SECURITY.md](SECURITY.md) |
| Project / copyright inquiries | [https://yankidev.com](https://yankidev.com) |

## Before opening an issue

1. Search existing issues and discussions.
2. Check the relevant category README under `docs/`.
3. Include the document path and what is unclear or incorrect.

## What this project is (and is not)

**Is:** a curated collection of learning and reference materials aligned with
industry and enterprise practices.

**Is not:** paid consulting, official certification training, or a substitute
for your organization’s compliance, legal, or security review.

## Response time

Community support is best-effort. Maintainers will prioritize clear, reproducible
content issues and high-impact corrections.
